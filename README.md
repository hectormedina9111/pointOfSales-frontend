# Punto de venta: frontend

Frontend web del sistema punto de venta, en Angular 22 con TypeScript, Bootstrap 5.3 y ng-bootstrap. Consume la API REST del backend ([pointOfSales](https://github.com/hectormedina9111/pointOfSales)).

El plan está en `docs/plan.md` del backend, sección "MVP del frontend (Angular)". Las instrucciones para levantar el proyecto llegan con el paso 1.
